rclone is mounting {{ .Values.rclone.remote }} on every node at {{ .Values.rclone.path }}{{ if .Values.rclone.readOnly }} (read-only){{ end }}.

Check the pods are running and the mount is up:

  kubectl get pods --namespace {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl logs --namespace {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }} -c rclone

To use the files in another workload, mount the same host path with
HostToContainer propagation so the pod sees the FUSE mount:

  volumes:
    - name: rclone
      hostPath:
        path: {{ .Values.rclone.path }}
  containers:
    - volumeMounts:
        - name: rclone
          mountPath: /data
          mountPropagation: HostToContainer
